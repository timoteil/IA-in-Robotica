# Reinforcement Learning in One Hour

A deterministic, tabular introduction: from Bellman's equation to Q-learning. It is the short version of the
longer course in `../rl_course/`, rebuilt around ideas from Lewis & Vrabie, *Reinforcement Learning and Adaptive
Dynamic Programming for Feedback Control* (IEEE Circuits and Systems Magazine, 2009), and based on David Silver's
UCL / DeepMind lectures.

**No probabilities, no policy iteration, no bandits, no exploration strategies, no function approximators.**
Every value in this course lives in a table you can print.

```
rl_course_1h/
├── requirements.txt             numpy, matplotlib
└── labs/
    ├── gridworld.py             the deterministic world: model env.model(s, a) and simulator env.step(a)
    ├── lab1_value_iteration.py  planning with a model
    └── lab2_q_learning.py       learning from data, with a probing agent and a greedy one
```


## Setup

Python 3.9 or newer.

```bash
pip install -r requirements.txt
cd labs
```

Each lab saves a figure to `labs/outputs/` and prints its results. Add `--show` to also open the plot window.

## Lab 1: value iteration on a gridworld

```bash
python lab1_value_iteration.py                 # gamma = 0.95: the route to the far goal
python lab1_value_iteration.py --sweeps 3      # stop after 3 sweeps: the wave of value
python lab1_value_iteration.py --gamma 0.5     # a short-sighted agent
```

The agent is allowed to ask the model `env.model(s, a)` for any state and any action. Expected: 8 sweeps, a 6-move
route to the far goal G, and V(S) = +0.683, which equals the discounted return of that route. With `--gamma 0.5` the
agent takes the 2-move route to the near exit E instead (V(S) = +0.130); the switch happens at γ ≈ 0.78.

## Lab 2: Q-learning without a model

```bash
python lab2_q_learning.py                      # probing agent
python lab2_q_learning.py --behaviour greedy   # greedy agent
python lab2_q_learning.py --compare            # both, side by side
```

The agent never calls `env.model`: it only calls `env.reset()` and `env.step(a)`. Value iteration from Lab 1 is
imported only to check the answer. The default run prints every transition of the first episode (state, action,
reward, next state, target, TD error), so one update can be checked by hand.

Expected: the probing agent reaches E in episode 1 and G in episode 4, all 18 values equal value iteration's from
episode 79 on, and its route is the 6-move one (V(S) = +0.683). The greedy agent finds E in episode 1, never tries
anything else, and ends with V(S) = +0.265 and none of the 18 values correct. With `--alpha 0.5` the table still
converges, more slowly (try `--episodes 500`).

Every lab file lists exercises at the top of its docstring.

## Design notes

* `gridworld.py` offers the same deterministic world in two ways: the **model** `env.model(s, a)`, which can be
  queried for any state and action (dynamic programming), and the **simulator** `env.reset()` / `env.step(a)`,
  which can only be advanced from where the agent is (learning). This makes the planning-versus-learning contrast
  concrete.
* Because the world is deterministic, the Q-learning update can use a step size α = 1: the new estimate replaces the
  old one, and the update is exactly value iteration done with samples. `--alpha` is there for the exercise.
* "Probing" means that the k-th time the agent is in a state it tries action k mod 4, whatever the table says. It is
  the simplest deterministic way to make the data cover every state–action pair. It is not an exploration strategy
  in the sense of ε-greedy or UCB, which are deliberately not covered.
* Value iteration is synchronous (it reads the previous table and writes a new one), so "V after k sweeps" is well
  defined: the best total reward collectable in k moves.
* Every number and figure in the slides is produced by these scripts.
